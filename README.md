# Bünyamin TAMA — kişisel portfolyo

Tek sayfalı, mobil uyumlu ve Türkçe bir kişisel site. HTML, CSS ve küçük bir JavaScript dosyasıyla hazırlanmıştır; derleme adımı veya bağımlılık kurulumu gerekmez.

## Kişiselleştirme

Kimlik ve iletişim bilgileri eklendi. Yayına almadan önce index.html içindeki örnek proje kartlarını ve yetenekleri kendi gerçek çalışmalarınızla güncelleyin:

- Üç proje kartının başlığı, açıklaması, yılı ve etiketleri
- Yetenekler ve çalışma alanlarınız
- İsterseniz GitHub profil bağlantısı

Renkleri ve düzeni style.css dosyasındaki :root değişkenlerinden ayarlayabilirsiniz. Mobil menü ve otomatik yıl script.js içindedir.

## Yayınlama

GitHub Pages ile bu depo üzerinden yayınlanabilir. index.html, style.css ve script.js dosyaları depo kökünde yer almalıdır.
